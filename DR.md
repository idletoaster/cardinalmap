# Disaster Recovery — cardinalmap

## Where data lives

- **Code:** GitHub repo `idletoaster/cardinalmap` (3 branches pushed:
  `main`, `upgrade/state-import`, `rollback/legacy-db`).
- **PostgreSQL databases:** `cardinalmap` (legacy, ~86 MB) and
  `cardinalmap_upgraded` (new state-import database, ~257 MB). Local
  to this host. Captured via `pg_dump -Fc` to a temp dir, then into
  restic.
- **Restic backup:** `google-drive:backup/cardinalmap`, 5-day retention.
- **Backup cron:** `30 3 * * *   /home/pawan/bin/backup-125.23.sh`

## What is captured by restic

`/home/pawan/cardinalmap` (excluding `node_modules/`, `.git/`, `.env*`,
`*.log`) **plus** the two `pg_dump` files produced on the fly, both
under `/tmp/cardinalmap-dbdump-<timestamp>/`.

So captured non-regenerable assets:
- `backups/cardinalmap-legacy-backup-20260930-221851.dump` (the 44 MB
  pre-cutover binary dump kept locally)
- `sql/`, `migrations/`, `config/`, `scripts/`, `src/`, `public/`
- the per-day `cardinalmap.dump` and `cardinalmap_upgraded.dump` from
  pg_dump (`-Fc`, compressed, custom format - restored with
  `pg_restore`)

## What is NOT in restic

- `node_modules/` (regenerated by `npm install`)
- `.env*` (postgres password, admin token; recreate on a fresh host)
- `.git/` (the repo itself is on GitHub)

## On a fresh Ubuntu host

1. Install runtime dependencies:
       apt install -y postgresql postgresql-XX-postgis build-essential curl
       curl -fsSL https://rclone.org/install.sh | sudo bash
       apt install -y restic
2. Clone the code at the right branch:
       gh repo clone idletoaster/cardinalmap
       cd cardinalmap && git checkout upgrade/state-import   # or main
3. Drop `~/.config/rclone/rclone.conf` (mode 600) and
   `~/.secrets/restic_passphrase_cardinalmap` (mode 600).
4. `cp .env.example .env` and fill in credentials.
5. Recreate the postgres role + databases:
       sudo -u postgres createuser -s <PGUSER>
       sudo -u postgres createdb -O <PGUSER> cardinalmap
       sudo -u postgres createdb -O <PGUSER> cardinalmap_upgraded
       sudo -u postgres psql -d cardinalmap -f sql/001_extensions.sql
6. `bash ~/restore-125.23.sh` to restore the cardinalmap folder and
   print the `pg_restore` commands (the dumps sit at
   `/tmp/cardinalmap-restore/...` after restore).
7. `cd ~/cardinalmap && npm install`
8. `npm run pm2:start && pm2 save`

There's also a self-contained wrapper at
`/home/pawan/restore-125.23.sh` on the source host that performs steps
3, 5, 6 and prints the rest.
